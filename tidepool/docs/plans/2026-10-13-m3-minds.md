# Tidepool M3 — Minds

Status: **draft of 2026-10-13. It waits for the owner. Build nothing from it.** Six choices are open,
in the next section. The rest of the plan is written with the recommended option of each, and each
choice names the tasks that change if the owner picks another.

**Goal:** After a long headless run, brains in one world differ in shape and are not all minimal. A
player can watch their own brain while they play, let go, and see it take over. Two creatures that
touch and both agree mix their genes, and an NPC can refuse the player.

**Architecture:** The brain of M2 has one shape for every creature. In M3 a brain genome is a list of
hidden neuron genes and a list of connection genes. A connection names its two ends by who owns them:
the body, a part gene, or a hidden neuron gene. It does not hold an index. So two genomes line up by
history id, and a part that is lost takes its inputs with it. The parts of a body decide which inputs
its brain has. Mutation adds and removes hidden neurons and connections. The page gets a brain viewer
for the possessed body and a card for mate choice. Full detail: `../architecture.md`.

**Tech stack:** unchanged from M2. Rust 1.99.0, TypeScript 6, Vite 8, Vitest 4, ESLint 10, pnpm 11,
Preact 11.

**Read first:** `../../AGENTS.md`, `../findings/m2-exit.md`, `../findings/m2-audit-2.md`,
`../findings/m2-senses.md`, `../findings/m2-tuning.md` (the Result and trials 6 to 9),
`../decisions/INDEX.md`, `../design.md` §5.6, §6, and §13, `../gates.md`.

## Differences from the roadmap and the design, to approve with this plan

1. **A Chemoreceptor still sums its genes and reads the scent at the centre of the body.** Its three
   inputs are declared once for a body that has the kind. An Eye declares per gene (choice C2).
2. **No part declares an output in M3.** `thrust`, `turn`, and `accept` belong to the body.
   `design.md` §6 gives each ability part one trigger output, and abilities arrive in M4.
   `brain::ports` is the one function that M4 extends.
3. **Own-body inputs are a constant, energy, age, speed, and two mate inputs.** Hunger is the energy
   input. Damage and its side arrive in M4 with the bite.
4. **The brain viewer shows the possessed body only.** A brain cannot be compared with an
   ancestor's until M5 builds the lineage tree. Any creature in Watch is M7.
5. **A gene donor is stored as one uid on the child.** The tree with donor cross-lines is M5.
6. **Audit finding L9 is not fixed.** A child that is never born still uses up ids. The counter is a
   `u32`, and a world would need about 2.8 billion ticks to reach its top.
7. **Brain blocks keep one size.** `architecture.md` §5.5 keeps size classes for a measured need.
8. **The brain bands are in `make gates-long` only**, not in `make gates` and not in CI.

## The rules

One reference brain: **the M2 founder with an eye.** 11 inputs, 4 hidden neurons, 2 outputs, 57
connections. It pays `0.0012 * 17 + 0.0003 * 57 = 0.0375` per tick.

**B1. Names.** A neuron has a name: `Node { owner, port }`.

```rust
// genome.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub struct Node { pub owner: u32, pub port: u8 }
pub const BODY: u32 = 0;                 // the owner of every port that the body declares
pub const PORT_HIDDEN: u8 = 255;         // the one port of a hidden neuron. Its owner is the gene's id

pub struct HiddenGene { pub id: u32, pub bias: f32, pub alpha: f32 }
pub struct OutGene { pub node: Node, pub bias: f32, pub alpha: f32 }
pub struct ConnGene { pub src: Node, pub dst: Node, pub weight: f32, pub history: u32 }
pub struct BrainGenome { pub hidden: Vec<HiddenGene>, pub outs: Vec<OutGene>, pub conns: Vec<ConnGene> }
pub const MAX_HIDDEN: usize = 64;
pub const MAX_CONN_GENES: usize = 384;   // brain::MAX_CONNS
```

The id of a hidden gene, the history of a connection, and the history of a part all come from
`World::next_history`. So no two genes of a world share a number, and an owner is never ambiguous.

**B2. Ports: who declares what.** `brain::ports(&Genome) -> Ports` is the only place that knows.

```rust
// brain.rs
pub struct Ports { pub inputs: Vec<Node>, pub outputs: Vec<Node> }
// The body. Always there, at these indexes.
pub const IN_CONST: u8 = 0;       pub const IN_ENERGY: u8 = 1;   pub const IN_AGE: u8 = 2;
pub const IN_SPEED: u8 = 3;       pub const IN_MATE_SIZE: u8 = 4; pub const IN_MATE_KIN: u8 = 5;
pub const N_BODY_IN: usize = 6;
// A body with a chemoreceptor sum above 0. Owner BODY.
pub const IN_SCENT: u8 = 16;      pub const IN_GRAD_FWD: u8 = 17; pub const IN_GRAD_SIDE: u8 = 18;
// One eye gene. Owner: the history id of the gene. A is the cone at +anchor * PI, or the one cone
// of a midline eye. B is its mirror. A midline eye has no B ports.
pub const EYE_FOOD_A: u8 = 0;     pub const EYE_BODY_A: u8 = 1;
pub const EYE_FOOD_B: u8 = 2;     pub const EYE_BODY_B: u8 = 3;
// The body. Always there.
pub const OUT_THRUST: u8 = 128;   pub const OUT_TURN: u8 = 129;   pub const OUT_ACCEPT: u8 = 130;
```

Input order in a brain block: the body inputs, then the scent inputs, then the eye genes in gene
order with A before B. A cone that `Creatures::express` does not make, past `MAX_EYES`, declares no port. Then
the hidden genes in gene order, then the outputs in the order above.

**B3. Expression.** `Brains::express(slot, &Genome, &Params)` turns names into indexes. A connection
with an end that the genome does not declare is not expressed and costs nothing. Connections are
sorted by (dst index, src index, history), as in M2, so a sum is made in one order on every target.
The weight of a connection whose source is a hidden neuron is times `hidden_gain`.

`Genome::prune()` runs on every genome that a birth makes, after crossover and mutation. It removes
each connection with an undeclared end, the second connection between one pair of ends (the lower
history stays), and the `OutGene` of an output that is not declared. It adds an `OutGene` with bias
0 and alpha 1 for a declared output that has none. So a living genome holds what its body expresses.

**B4. The eye inputs.** Each cone feeds two inputs of its own gene: the nearness of the nearest plant
in the cone, and of the nearest body. Nothing is summed by side. The scan of `eye::see` does not
change.

**B5. The mate inputs.** `IN_MATE_SIZE` is `other / (own + other)` in grown area, for the nearest
body that this body touches. `IN_MATE_KIN` is `1 - 2 * d`, where `d` is the distance between the two
hues around the circle, 0 to 0.5. Both are 0 with no body in touch. The motor already finds every
overlap for the push: it also keeps the nearest one of each body. `mate::step` reads that in the same
tick and stores the two values on the creature. They are saved. `sense::step` copies them on the
next think.

**S1. Structural mutation.** Four groups after the five of M2, in this order. A rate of 0 makes no
draw. Each draws its chance first and the rest only if the mutation happens.

6. Remove a connection (`mut_conn_remove`): one chosen evenly.
7. Remove a hidden neuron (`mut_neuron_remove`): one chosen evenly. Its connections go with it.
8. Add a connection (`mut_conn_add`, with room): a source chosen evenly from every declared neuron,
   a target chosen evenly from the hidden neurons and the outputs, a weight of
   `gauss * new_conn_sigma`. If the pair is joined already, the three draws are made and nothing is
   added. A loop and a self-loop are allowed.
9. Add a hidden neuron (`mut_neuron_add`, with room and at least one connection): one connection
   chosen evenly is split. It is removed. A hidden gene with bias 0 and alpha 1 takes a new id. A
   connection from the old source to it has weight 1, and one from it to the old target has the old
   weight. Three new numbers from `next_history`.

**S2. A part and its wires.**
- Add (group 5 of M2): if the new part makes new ports, it arrives with `part_wires` connections.
  Each: a source chosen evenly from its new ports, a target chosen evenly from the hidden neurons
  and the outputs, a weight of `gauss * new_conn_sigma`.
- Duplicate (group 4): every connection that names the original is copied for the copy, with a new
  history each. No draw.
- Remove (group 3): `prune` removes what named it. No draw.

**U1. Brain upkeep** (choice C1).
`upkeep = basal * m + fixed_upkeep + neuron_upkeep * hidden + conn_upkeep * conns + move`, then
times the old-age factor of rule L1. `hidden` and `conns` are the expressed counts. An input or an
output neuron costs nothing. A juvenile pays `fixed_upkeep` in full, as it pays the whole brain
today.

**X1. Mating.** `mate::step` runs after the motor, in the contact phase. With `mix_rate` at 0 it
returns at once. For each live slot `s` in ascending order: `s` and the nearest body `j` that it
touches make a pair if `j > s`, both are full-grown, both hold no donor, both have `cmd_accept`
above 0, and neither is in a pair of this tick. With chance `mix_rate`, drawn from `rng_mate`, each
takes a copy of the other's genome and its uid as its donor. A body holds one donor until its next
bud.

**X2. Crossover.** `mix::cross(home, donor, rng, p) -> Genome`. Draws in this order.
1. `len`, `wid`, `egg`, `old`: each from the donor with chance `mix_swap`. The hue is the home's: a
   lineage keeps its colour.
2. Each home part in gene order: if the donor holds its history, its anchor, size, and `extra` come
   from the donor with chance `mix_swap`.
3. Each part that only the donor holds, in the donor's order: taken with chance `mix_foreign`, while
   there is room.
4. Each home hidden gene: if the donor holds its id, bias and alpha from the donor with chance
   `mix_swap`. Then each hidden gene that only the donor holds: chance `mix_foreign`, with room.
5. Each home `OutGene`: bias and alpha from the donor with chance `mix_swap`.
6. Each home connection: if the donor holds its history, the weight from the donor with chance
   `mix_swap`. Then each connection that only the donor holds: chance `mix_foreign`, with room.

`repro::step` makes each child of a brood from `cross(...)` if the parent holds a donor, and from
the parent's genome if not. Then `mutated`, then `prune`. The child stores the donor's uid in
`mixed_with`. The parent's donor is cleared after a bud that made a child.

**X3. The player courts.** `tp_input` gains a fourth value, `accept`. While the input is manual, the
`cmd_accept` of the possessed body is 1 with `accept` and -1 without. With the controls released the
brain decides, as for every other output.

**G1. The control arm.** `hidden_gain` is 1. At 0 a hidden neuron sends nothing: it still costs and
still mutates. `gate-evolve --brain` runs one more world per seed at 0.

## The throughput budget

The floor is 2,400 ticks per second: 417 microseconds per tick. The bench world reads 2,933 to
3,127: 320 to 341 microseconds, with 1,320 creatures. The room is 76 to 97 microseconds per tick.

A brain steps on every second tick, so a tick holds 660 brain steps. At 1.4 ns per connection,
**100 more connections per brain cost 92 microseconds per tick.** That is the whole room. So:

- The mean of `conns` in the bench world is a number that every gate row prints from Task 9.
- Target after the retune: 2,700 ticks per second or more in WASM at a mean of 1,200 creatures or
  more. That is about 30 more connections per brain than a founder has.
- If the reading is under the target, the levers of Task 10, in order.
- If it is still under 2,400, stop and report. The floor and the reference population are the
  owner's.

The old world of M2 (tick 108,000, 1,665 creatures) is under the floor already and is carried to M5.
Task 10 reads it again with no band.

| Name | M2 | Start | Meaning in M3 |
|---|---|---|---|
| `neuron_upkeep` | 0.0012 | 0.0002 | Upkeep per hidden neuron per tick |

`fixed_upkeep` is what is left of 0.0375 for the founder of Task 6, which has 4 hidden neurons and 60

**Known soft spots.** Read these before approving.

1. **A brain may have little to think about until M4.** The world of M3 holds plants that never die
   and no hunter. Most of what pays there is a straight wire from a sense to a motor. A hidden
   neuron pays only where a body must do two things with one sense, and no run has shown that it
   does. So target 5 can fail after the cost is at 0. That is then a finding for the owner, with two
   options that this plan does not take by itself: ship M3 with brains that evolution does not grow
   and judge them again in M4, or hold the brain bands until M4 gives a brain a hunter to answer.
2. **65 generations is a short time.** The bands can show that structure is kept or lost. They
   cannot show that evolution builds a new circuit. The plan claims the first only.
3. **Rule U1 is an argument that the body holds, not a measurement.** A founder pays the same. An
   evolved body can now shed a tenth of that cost by shedding wires. If `len` slides, rule 2 of
   Task 10 part 3 is the answer, and it worked once in M2.
4. **Per-gene eye inputs can weaken the eye gap,** which has little room. A copied eye starts with a
   copy of the wires, so it should work at once. Task 6 reads 10 seeds and stops if the gap fails.
5. **Throughput has room for about 30 more connections per brain.** With no cost a brain drifts
   toward 384. Rule 3 of the retune names the levers, and the second one is the owner's.
6. **`accept` may stick open,** as the draft's three gates did. A founder accepts always. A body
   gains from refusing only if some partners are worse than none, and nothing here shows that. Then
   an NPC never refuses the player and the card always says "willing". Part 4 of Task 10 reads it.
7. **Mixing can blur what the world has sorted.** A cross of two body plans can be worse than both.
   Budding alone keeps a lineage whole, so the world cannot die of it, but the gaps and `len` can
   move. Stage 2 has 3 trials and a stop.
8. **Task 1 is large.** It touches every file of the core, as Task 2 of M2 did. The M2 rows are its
   test, and they are cheap.
9. **The viewer is a feel question.** No agent can say whether a graph of 17 to 40 neurons reads at a
   glance. Owner checks 1 to 3 decide it. The cheap changes if it reads badly: fewer weak wires
   drawn, and larger groups.
10. **The long gate grows to about 16 minutes** and still reads one run per seed.
11. **Brains will differ by ports with no brain mutation at all.** A third of the bodies on 2 of 10
    seeds hold no chemoreceptor at tick 144,000, and under C2 they have 3 fewer inputs and fewer
    wires. That is a true difference between brains, and the player will see it in the viewer. It is
    not evidence that structural mutation is used. The `shapes` proof in Task 9 keeps the two apart.
