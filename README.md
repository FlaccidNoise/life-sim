# life-sim

An emergent artificial-life simulator: free-floating cells on a 2D toroidal
plane interacting via physics forces, binding into multicellular organisms,
with neuron-cell neural networks, developmental genomes, and evolution driven
by an energy economy.

## Status
Milestones **M0–M7 complete**, **M7.5 (ecology) merged**: a self-sustaining 3-trophic ecosystem
(plants → foragers → predators) of multicellular organisms with developmental genomes, evolvable
neuron-cell brains, and mutation under purely-economic selection — plus a live environmental layer
(day/night cycle, temperature, toxins, bioluminescence, currents, rocks). WebGL2 viewer with
pan/zoom + time controls. Decision log in `docs/decisions/INDEX.md`; milestone plans in
`docs/superpowers/plans/`.
