  on 5 errors in the new graze-latch test files). Every other plan's done
  criteria call `make check`; the gate must be green first. 001 is a ~5-char

- **002 before 004.** 004 refactors `metabolize()` (31 → 10 args). Its safety
  net is the byte-identical reproducibility contract — but the OFF-path
  reproducibility tests do NOT cover the graze/satiation branch 004 touches.

  means a behavior change in the graze branch could slip through unchecked.
  Hard dependency.

  overlap). Can run in parallel with 002 after 001 lands.
- **005 vs 004.** No hard dependency, but both edit `src/core/sim/world.ts`
  near scan sites / the `metabolize` call site. Run them in sequence (either
  order) to avoid merge churn, not in parallel.
- **005 A1b-organisms is conditional** — see plan 005 Step 2 / STOP
  conditions. If the organism id scheme is non-LIFO, that sub-phase is
  deferred (A1b-bonds + A2 still land).
- **005 A2 follow-up (OPEN):** the generation-stamp change eliminated the
  `counts.fill(0)` memset (the dominant O(area) cost) and is byte-identical,
  but the prefix-sum loop in `SpatialHash.build` still scans all
  `cols*rows` buckets, so per-tick cost is not perfectly area-flat (bench:
  1.107→1.438 ms/tick over 16× area — the O(area) cliff is broken, ~1.3×
  growth remains). Making the prefix sum O(occupied) requires sorting
  touched bucket indices; deferred as a follow-up. The 492-test suite (incl.
  byte-identity) is green.
- **004 scope note:** the executor found 3 `metabolize` callers beyond the
  plan's 2 listed test files (`base-toughness.test.ts`,

  them to scope, per the plan's STOP condition. Sanctioned.
- **001 deviation note:** the plan's `_cfg` rename didn't suppress the
  unused-var error (the repo eslint config has no `argsIgnorePattern`), so
  the executor used `// eslint-disable-next-line @typescript-eslint/no-unused-vars`.
