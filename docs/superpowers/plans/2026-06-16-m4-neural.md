# M4 — Neural Nets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add neuron-cell recurrent neural networks (snapshotted synapse topology, double-buffered THINK step at tick step 3) and a hand-wired multicellular critter — SENSOR + NEURON + MOVER cells — that swims to food via its brain, replacing the M3 hardcoded reflex for the new critter while leaving the M3 MOTILE ecosystem untouched (spec §8 M4 acceptance, §4.6, §5.2, §10 R3, §11).

**Architecture:** A new pure `core/neural/` module owns a flat SoA **synapse pool** (free-list + gen-validated endpoints, NOT bit-packed — §4.2/§5.2) and a **double-buffered neuron-activation buffer** indexed by cell slot. THINK (tick step 3) runs one synchronous forward pass of `a_j(t) = tanh(bias_j + Σ_i w_ij·a_i(t−1))` between the existing SENSE (step 2) and ACT (step 4) seam that M3 deliberately left open. Sensor cells inject the body-frame food gradient as their activation each tick; output (motor) neurons drive a MOVER's thrust/turn at ACT. The critter coheres without bonds via a **kinematic rigid grouping**: passenger cells (SENSOR/NEURON) are repositioned each tick at fixed body-frame offsets from the integrated MOVER body (no springs, no intra-critter repulsion). M5 replaces the kinematic grouping with real bond physics + intra-organism energy transfer.

**Tech Stack:** TypeScript 6 strict, Vitest 4 (`--expose-gc` via NODE_OPTIONS), WebGL2, Vite 8, pnpm 11, Node 22. Determinism is an engineered invariant; the hot loop is allocation-free; activations are Float32 (`toBeCloseTo`, never `toBe`).

**Hardened by adversarial audit (2026-06-16):** an 8-lens multi-agent audit (each finding independently verified) confirmed 7 blocker/major issues, all fixed in this revision: (1) critter cells would divide on tick 1 (reserve ≫ divideThreshold + the new `isLiving`) → neural cells are now exempt from lifecycle death + division (Task 1); (2) a self-contradicting "gen-validate every tick" invariant → corrected to the snapshot model + dropped the vestigial `generation` param; (3) the acceptance test's gradient was Float32-zero at the start → geometry now mirrors the proven `chemotaxis.test.ts` (small torus, off-axis food); (4) zero-alloc pool was already full → capacity raised + spawns asserted; (5) Task 9↔10 circular ordering → split (Task 9 Step 0 adds World members first). Plus: per-World organism-id (no global state), a closed-form through-`tick()` golden assertion, an oscillator/recurrence test, a layout-clearance assertion, and an `aliveCount` topology-regression guard.

## Decisions locked with Josh (2026-06-16)

1. **Kinematic rigid grouping** for critter cohesion. One integrated MOVER body; SENSOR/NEURON cells are passengers placed each tick at fixed body-frame offsets (`bodyPos + R(heading)·offset`), velocity/force zeroed. No bonds, no springs, no intra-critter repulsion (offsets are larger than contact range). M5 replaces this with real bond physics.
2. **Add `SENSOR`=4, `NEURON`=5, `MOVER`=6** (extend, do not renumber). **Keep `MOTILE`=3** — the verified M3 trophic ecosystem depends on it ([[m3-trophic-dynamics]]); the hand-wired critter is built from the new types and is non-edible (not PHOTO/MEAT), so it does not perturb the economy.
3. **Brain I/O:** inputs = food-gradient projected into the body frame (FWD_GRAD, LAT_GRAD sensor channels) + an internal recurrent clock/oscillator; outputs = 2 motor neurons → thrust magnitude + turn. Expandable later (own energy, ambient light, density — §4.6 vocabulary).
4. **`neuralCost`** present-but-small live knob now (§4.5): charged per neural-type cell per tick in METABOLIZE, so a brain isn't free. Per-synapse cost deferred (note it).

## Invariants to preserve (do NOT regress)

- **`World.tick` stays allocation-free.** The `--expose-gc` zero-alloc test ticks 50k cells × 500 (30s timeout). Pre-allocate ALL scratch in constructors: the synapse pool, the two activation buffers, all binding tables, all live lists. No per-tick literals/closures/`.map`. THINK iterates the pre-built live-synapse list, accumulates into the write buffer, applies `bias`+`tanh`, then World swaps the buffer pointers (pointer swap, no copy).
- **`core/cells` & `core/environment` & `core/neural` take SCALAR params or raw arrays, never `Config`.** `World.tick` unpacks `cfg.*` at the call site (matches `computeRepulsion`/`integrate`/`metabolize`/`sense`/`act`). `core/physics` takes raw typed arrays, never `CellArrays`. The new `core/neural/` module sits above `memory`, alongside `cells` in the §5.1 DAG; it imports `math`/`memory`/`cells` only.
- **Determinism:** byte-identical arrays for `(Config, seed)`, now including neuron activations. Canonical ascending iteration order (live-synapse list and live-neuron list are built in ascending slot order). THINK draws **NO RNG** in M4 (no neural noise — confirmed minimal); if future neural init/noise is added it must use `rng.split(2)` (light uses `split(1)`, M3 reflex uses none). New per-cell neural state (bias, activation) is deterministic (zero-init; the critter builder sets explicit values).
- **`energy` is `Float32Array`** → assert energies near 100 at `toBeCloseTo(…, 4)`. **Activations are `Float32Array`** → assert with `toBeCloseTo(…, 5)`; never `toBe(literal)` (0.7 stores as 0.69999998).
- **Safe references (§4.2):** synapse endpoints store `(slotIndex, generation)` in separate parallel arrays — NEVER bit-packed. Endpoint validity is established ONCE by `rebuildLive` on structural events (cell/synapse birth/death), per the §4.6 snapshot rule — THINK does **NOT** re-validate generation per tick (that would add a per-synapse `generation[]` read to the allocation-free hot loop and contradicts §4.6 "never recomputed per tick"). The only per-tick guard inside THINK is a cellType re-check on each live-neuron slot (a slot recycled to a non-neural type since the snapshot is skipped). **In M4 the topology is genuinely immutable at runtime:** neural cells never divide, die, or free their slots (Task 1 exempts `isNeural` cells from lifecycle death + division), so no synapse can ever dangle during a run; `rebuildLive`'s gen-validation is the M5 forward-compat path for when neural-cell death/organism-split lands.
- **Positions Float64; render downcasts.** The MOVER moves fast; passengers are snapped to the rigid layout each tick — verify the renderer's `prevGen`/NaN-prev de-streak still looks right for the new types (Task 16 capture).
- **Spatial hash is built on pre-integrate positions (unchanged).** THINK does NOT use the hash — it uses the snapshotted synapse topology, NOT positions (§4.6: never recompute topology from positions per tick). The kinematic reposition runs AFTER integrate.
- **Do not renumber `CellType`.** PHOTO=0, DIGESTIVE=1, MEAT=2, MOTILE=3 are stable; append SENSOR=4, NEURON=5, MOVER=6.

## Tick READS/WRITES additions (apply to `src/core/sim/READS-WRITES.md` in Task 11)

New/changed steps (spec §4.3 order; THINK = step 3 is now LIVE):

| # | Step | Reads | Writes |
|---|---|---|---|
| 2b | **SENSE** (extended) | cellType, pos; previous tick's food field | senseX, senseY (**MOTILE and SENSOR**) |
| 3 | **THINK** | sensor bindings + senseX/senseY + heading (sensor injection, body-frame projection); snapshotted live-synapse pool (pre/post); `actCur` (a(t−1)); bias; cellType (per-neuron re-check) | `actNxt` then **swap** → `actCur` holds a(t); (SENSOR/NEURON/MOVER activations) |
| 4 | **ACT** | MOTILE: cellType/senseX/senseY/heading (existing reflex). **driveMovers**: motor bindings + `actCur`[turn/thrust neuron] + heading | heading, thrust (MOTILE reflex **and** MOVER from neurons) |
| 5b | applyThrust | heading, thrust | forceX, forceY (MOTILE + MOVER) |
| 6b | **repositionPassengers** (after integrate) | rigid-group table; body pos/heading | passenger posX/posY/heading; passenger velX/velY/forceX/forceY ← 0 (kinematic override) |
| 7 | METABOLIZE (extended) | + thrust; + cellType (neural) | energy (− moveCost·thrust² for MOVER; − neuralCost for SENSOR/NEURON/MOVER) |

Coupling notes (add all to the file):
- **Sensor→neuron→mover within a tick:** SENSE (step 2) writes the world-frame gradient THIS tick → THINK (step 3) injects the **body-frame** projection into the sensor's `actNxt` and computes neuron/motor activations → after the buffer swap `actCur` holds a(t) → ACT (step 4) reads `actCur`[motor neuron] THIS tick to drive the MOVER. So THINK→ACT is same-tick (no lag). The **recurrent term reads a(t−1)** (`actCur` before the swap): every synapse path carries an inherent one-tick delay (sensor→hidden→output reaction lag of 1 tick per synapse — standard for a synchronous recurrent net, imperceptible for chemotaxis). The internal clock is built from recurrent neuron synapses and demonstrates persistent activation with no external input.
- **THINK reads the food field indirectly:** sensors read `senseX/senseY` written THIS tick by SENSE, which itself read the PREVIOUS tick's food field (the M3 one-tick food coupling is unchanged).
- **Kinematic override:** `repositionPassengers` runs AFTER integrate and OVERWRITES passenger positions to the rigid body-frame layout, zeroing their velocity and force. Passengers are placed at offsets larger than the contact range so they never soft-repel the body or each other; any transient force the broad-phase imparts is erased by the reposition. Only the MOVER body integrates dynamically (thrust + drag + repulsion off the ecosystem). This is the M4 stand-in for M5 bond physics.
- **METABOLIZE charges THIS tick's thrust** (unchanged) and THIS tick's `neuralCost` for neural-type cells. Critter cells are provisioned with a large energy reserve by the builder (maternal-provisioning analog) for visual energy display, but **survival and topology-immutability do NOT depend on the reserve** — Task 1 exempts `isNeural` cells from lifecycle death (they never convert to MEAT) and from division (they never clone), so the hand-wired topology is fixed for the whole run regardless of energy. Intra-organism energy transfer (which would actually feed them) is M5. (My earlier "no income → never reaches divideThreshold" reasoning was wrong: division fires on `energy ≥ divideThreshold`, and the reserve starts far above it — the lifecycle exemption is the real mechanism.)

```ts
export const CellType = {
  PHOTO: 0,
  DIGESTIVE: 1,
  MEAT: 2,
  MOTILE: 3,
  SENSOR: 4,
  NEURON: 5,
  MOVER: 6,
} as const;

export type CellTypeValue = (typeof CellType)[keyof typeof CellType];

/** True for types that metabolize and age. MEAT is dead; all others live. */
export function isLiving(type: number): boolean {
  return type !== CellType.MEAT;
}

/** True for neural-network cells (sense / compute / actuate). They wire via synapses. */
export function isNeural(type: number): boolean {
  return type === CellType.SENSOR || type === CellType.NEURON || type === CellType.MOVER;
}

/** Can `eater` consume `prey`? Heterotrophs (DIGESTIVE, MOTILE) eat PHOTO + MEAT. */
export function isEdibleBy(eater: number, prey: number): boolean {
  return (
    (eater === CellType.DIGESTIVE || eater === CellType.MOTILE) &&
    (prey === CellType.PHOTO || prey === CellType.MEAT)
  );
}
```

```ts
import { type CellStore } from '../memory/cell-store';
import { isNeural } from '../cells/types';

/** Sensor channel = which scalar a SENSOR cell injects as its activation each tick. */
export const SensorChannel = {
  /** Food gradient projected onto the body's forward axis. */
  FWD_GRAD: 0,
  /** Food gradient projected onto the body's lateral (left/right) axis. */
  LAT_GRAD: 1,
} as const;
export type SensorChannelValue = (typeof SensorChannel)[keyof typeof SensorChannel];

/**
 * The recurrent neuron-cell network (§4.6). A flat SoA synapse pool with a
 * free-list and gen-validated endpoints (slot index + generation in SEPARATE
 * parallel arrays — never bit-packed, §4.2). Per-cell `bias` and a double-buffered
 * activation pair (`actCur` = a(t−1) entering THINK, a(t) after `swap`; `actNxt` =
 * write scratch) are sized to `maxCells` and owned here so the buffer swap is a
 * pointer exchange (CellStore SoA views cannot swap). Topology is snapshotted:
 * `rebuildLive` is called only on structural events, never per tick.
 *
 * One global network across all organisms in single-thread (THINK iterates the
 * global live-synapse list); M8 partitions by organism graph.
 */
export class NeuralNetwork {
  readonly maxCells: number;
  readonly maxSynapses: number;

  // Synapse SoA pool.
  readonly pre: Uint32Array;
  readonly preGen: Uint32Array;
  readonly post: Uint32Array;
  readonly postGen: Uint32Array;
  readonly weight: Float32Array;
  private readonly synAlive: Uint8Array;
  private readonly synFree: Int32Array;
  private synFreeTop: number;

  // Per-cell neural state (indexed by cell slot).
  readonly bias: Float32Array;
  actCur: Float32Array;
  actNxt: Float32Array;

  // Compact live lists, rebuilt on structural events (ascending slot order).
  readonly liveSynapses: Uint32Array;
  liveSynapseCount: number;
  readonly liveNeurons: Uint32Array;
  liveNeuronCount: number;

  // Sensor bindings: which cell injects which channel.
  readonly sensorCell: Uint32Array;
  readonly sensorChannel: Uint8Array;
  sensorCount: number;

  // Motor bindings: a MOVER reads (turnNeuron, thrustNeuron) activations.
  readonly moverCell: Uint32Array;
  readonly turnNeuron: Uint32Array;
  readonly thrustNeuron: Uint32Array;
  motorCount: number;

  constructor(maxCells: number, maxSynapses: number, maxNeurons: number) {
    this.maxCells = maxCells;
    this.maxSynapses = maxSynapses;

    this.pre = new Uint32Array(maxSynapses);
    this.preGen = new Uint32Array(maxSynapses);
    this.post = new Uint32Array(maxSynapses);
    this.postGen = new Uint32Array(maxSynapses);
    this.weight = new Float32Array(maxSynapses);
    this.synAlive = new Uint8Array(maxSynapses);
    this.synFree = new Int32Array(maxSynapses);
    for (let i = 0; i < maxSynapses; i++) this.synFree[i] = maxSynapses - 1 - i;
    this.synFreeTop = maxSynapses;

    this.bias = new Float32Array(maxCells);
    this.actCur = new Float32Array(maxCells);
    this.actNxt = new Float32Array(maxCells);

    this.liveSynapses = new Uint32Array(maxSynapses);
    this.liveSynapseCount = 0;
    this.liveNeurons = new Uint32Array(maxNeurons);
    this.liveNeuronCount = 0;

    this.sensorCell = new Uint32Array(maxNeurons);
    this.sensorChannel = new Uint8Array(maxNeurons);
    this.sensorCount = 0;

    this.moverCell = new Uint32Array(maxNeurons);
    this.turnNeuron = new Uint32Array(maxNeurons);
    this.thrustNeuron = new Uint32Array(maxNeurons);
    this.motorCount = 0;
  }

  /** Allocate a synapse; returns slot or -1 if the pool is full (refuse-new policy). */
  addSynapse(pre: number, preGen: number, post: number, postGen: number, weight: number): number {
    if (this.synFreeTop === 0) return -1;
    const s = this.synFree[--this.synFreeTop]!;
    this.pre[s] = pre;
    this.preGen[s] = preGen;
    this.post[s] = post;
    this.postGen[s] = postGen;
    this.weight[s] = weight;
    this.synAlive[s] = 1;
    return s;
  }

  /** Free a synapse slot (M5 structural events; provided for completeness). */
  freeSynapse(s: number): void {
    if (this.synAlive[s] === 0) return;
    this.synAlive[s] = 0;
    this.synFree[this.synFreeTop++] = s;
  }

  addSensor(cell: number, channel: number): void {
    const k = this.sensorCount++;
    this.sensorCell[k] = cell;
    this.sensorChannel[k] = channel;
  }

  addMotor(mover: number, turnNeuron: number, thrustNeuron: number): void {
    const k = this.motorCount++;
    this.moverCell[k] = mover;
    this.turnNeuron[k] = turnNeuron;
    this.thrustNeuron[k] = thrustNeuron;
  }

  /**
   * Rebuild the live-synapse and live-neuron lists (ascending slot order).
   * Synapses with a dangling endpoint (dead/recycled cell — generation mismatch)
   * are pruned. Call ONLY on structural events (cell/synapse birth/death), per the
   * §4.6 snapshot rule — never per tick.
   */
  rebuildLive(store: CellStore): void {
    const f = store.fields;
    // Live neurons: alive neural cells, ascending.
    let nn = 0;
    for (let i = 0; i < store.capacity; i++) {
      if (store.isAlive(i) && isNeural(f.cellType[i]!)) this.liveNeurons[nn++] = i;
    }
    this.liveNeuronCount = nn;
    // Live synapses: alive slot + both endpoints gen-valid, ascending.
    let ns = 0;
    for (let s = 0; s < this.maxSynapses; s++) {
      if (this.synAlive[s] === 0) continue;
      if (!store.validate(this.pre[s]!, this.preGen[s]!)) continue;
      if (!store.validate(this.post[s]!, this.postGen[s]!)) continue;
      this.liveSynapses[ns++] = s;
    }
    this.liveSynapseCount = ns;
  }

  /** Exchange the activation double buffer by reference (after THINK writes actNxt). */
  swap(): void {
    const t = this.actCur;
    this.actCur = this.actNxt;
    this.actNxt = t;
  }
}
```

```ts
import { type NeuralNetwork } from './network';
import { CellType } from '../cells/types';
import { SensorChannel } from './network';

/**
 * THINK step (§4.3 step 3) — one synchronous double-buffered forward pass of the
 * recurrent equation `a_j(t) = tanh(bias_j + Σ_i w_ij·a_i(t−1))` (§4.6, φ=tanh).
 * Reads `net.actCur` (a(t−1)); writes `net.actNxt`; the caller swaps afterwards so
 * `actCur` then holds a(t). Allocation-free; iterates the snapshotted live-synapse
 * and live-neuron lists; gen-validation of endpoints already happened in
 * `rebuildLive`, but each live-neuron slot's cellType is re-checked (a recycled
 * slot is skipped). NO RNG.
 *
 * Sensor cells are pure inputs: their activation is the food gradient projected
 * into the body frame (heading), NOT computed from synapses. Non-sensor neurons
 * (NEURON, MOVER) sum their incoming synapses over a(t−1).
 */
export function think(
  net: NeuralNetwork,
  cellType: Uint8Array,
  senseX: Float32Array,
  senseY: Float32Array,
  heading: Float32Array,
): void {
  const cur = net.actCur;
  const nxt = net.actNxt;

  // (a) Zero the write buffer for every live neuron slot (O(neurons), not O(cells)).
  const neu = net.liveNeurons;
  const nn = net.liveNeuronCount;
  for (let k = 0; k < nn; k++) nxt[neu[k]!] = 0;

  // (b) Accumulate recurrent synapse contributions into the write buffer (a(t−1)).
  const live = net.liveSynapses;
  const ns = net.liveSynapseCount;
  const { pre, post, weight } = net;
  for (let k = 0; k < ns; k++) {
    const s = live[k]!;
    nxt[post[s]!] = nxt[post[s]!]! + weight[s]! * cur[pre[s]!]!;
  }

  // (c) Inject sensor cells (body-frame projection) — overwrites their accumulator.
  const sc = net.sensorCell;
  const ch = net.sensorChannel;
  const sn = net.sensorCount;
  for (let k = 0; k < sn; k++) {
    const i = sc[k]!;
    if (cellType[i]! !== CellType.SENSOR) continue;
    const h = heading[i]!;
    const cos = Math.cos(h);
    const sin = Math.sin(h);
    const gx = senseX[i]!;
    const gy = senseY[i]!;
    nxt[i] =
      ch[k]! === SensorChannel.FWD_GRAD ? gx * cos + gy * sin : -gx * sin + gy * cos;
  }

  // (d) Apply bias + tanh to every non-sensor neuron (sensors already set in (c)).
  const bias = net.bias;
  for (let k = 0; k < nn; k++) {
    const j = neu[k]!;
    const t = cellType[j]!;
    if (t === CellType.SENSOR) continue; // injected, not squashed
    if (t !== CellType.NEURON && t !== CellType.MOVER) continue; // recycled slot
    nxt[j] = Math.tanh(bias[j]! + nxt[j]!);
  }
}
```

> Note: `generation` is deliberately NOT a parameter. Endpoint validity is established by `rebuildLive` on structural events, and M4 topology is immutable (Task 1 exempts neural cells from death/division), so THINK never needs to re-validate endpoints per tick (§4.6 snapshot rule + the keep-the-hot-loop-allocation-free invariant). The READS-WRITES THINK row must NOT list `generation` either.

```ts
import { type NeuralNetwork } from './network';

/**
 * Motor binding (§4.6 neuron→mover effector). For each MOVER, read its two motor
 * neurons' current activations (`net.actCur`, a(t) after the THINK swap): the turn
 * neuron rotates `heading` by `turnScale·a`, the thrust neuron sets
 * `thrust = clamp(thrustScale·a + thrustBias, 0, maxThrust)`. Allocation-free.
 * Runs at ACT (§4.3 step 4), same tick THINK wrote the activations (no lag).
 */
export function driveMovers(
  net: NeuralNetwork,
  heading: Float32Array,
  thrust: Float32Array,
  turnScale: number,
  thrustScale: number,
  thrustBias: number,
  maxThrust: number,
): void {
  const act = net.actCur;
  const mc = net.moverCell;
  const tn = net.turnNeuron;
  const hn = net.thrustNeuron;
  const n = net.motorCount;
  for (let k = 0; k < n; k++) {
    const m = mc[k]!;
    heading[m] = heading[m]! + turnScale * act[tn[k]!]!;
    let t = thrustScale * act[hn[k]!]! + thrustBias;
    if (t < 0) t = 0;
    else if (t > maxThrust) t = maxThrust;
    thrust[m] = t;
  }
}
```

```ts
/**
 * Kinematic rigid grouping (M4 stand-in for M5 bond physics). Each passenger cell
 * is snapped, after INTEGRATE (§4.3 step 6), to its body's position plus a fixed
 * body-frame offset rotated by the body heading, and inherits the body heading.
 * Velocity and force are zeroed so the dynamic integrate pass on the passenger
 * slot is overridden (passengers are kinematic; only the MOVER body integrates).
 * Positions wrap toroidally. Raw-array, allocation-free.
 */
export function repositionPassengers(
  passenger: Uint32Array,
  body: Uint32Array,
  offX: Float32Array,
  offY: Float32Array,
  n: number,
  posX: Float64Array,
  posY: Float64Array,
  heading: Float32Array,
  velX: Float32Array,
  velY: Float32Array,
  forceX: Float32Array,
  forceY: Float32Array,
  worldWidth: number,
  worldHeight: number,
): void {
  for (let k = 0; k < n; k++) {
    const p = passenger[k]!;
    const b = body[k]!;
    const h = heading[b]!;
    const cos = Math.cos(h);
    const sin = Math.sin(h);
    const ox = offX[k]!;
    const oy = offY[k]!;
    let x = posX[b]! + (ox * cos - oy * sin);
    let y = posY[b]! + (ox * sin + oy * cos);
    x = ((x % worldWidth) + worldWidth) % worldWidth;
    y = ((y % worldHeight) + worldHeight) % worldHeight;
    posX[p] = x;
    posY[p] = y;
    heading[p] = h;
    velX[p] = 0;
    velY[p] = 0;
    forceX[p] = 0;
    forceY[p] = 0;
  }
}
```

```ts
import { type World } from './world';
import { CellType } from '../cells/types';
import { SensorChannel } from '../neural/network';

export interface Critter {
  organismId: number;
  mover: number;
  sensorFwd: number;
  sensorLat: number;
  clockA: number;
  clockB: number;
  turn: number;
  thrust: number;
}

/**
 * §10 R3 hand-wired sensorimotor critter: a MOVER body with two front SENSOR cells
 * (forward/lateral food-gradient channels), a 2-neuron recurrent clock (search
 * oscillator — demonstrates persistent activation), and two output NEURONs (turn,
 * thrust) the MOVER reads. Built deterministically; cells are provisioned with a
 * large energy reserve (maternal-provisioning analog) so the critter survives the
 * demo horizon without M5 intra-organism transfer, and never reaches divideThreshold
 * (no income) so the topology is never corrupted by division.
 *
 * Passenger offsets exceed the contact range (2·cellRadius) so the kinematic group
 * never soft-repels itself; positions are snapped each tick by repositionPassengers.
 */
export function spawnSwimmer(world: World, x: number, y: number, heading: number): Critter {
  const f = world.cells.fields;
  const r = world.config.cellRadius;
  // Per-World deterministic organism id (no module-global state → no cross-test/cross-run
  // determinism hazard; two fresh Worlds both start at 1).
  const org = world.nextOrganismId++;
  const RESERVE = 5000;

  const make = (type: number, ox: number, oy: number): number => {
    const i = world.cells.alloc();
    if (i < 0) throw new Error('spawnSwimmer: out of cell slots');
    // initial position = body-frame offset rotated by heading (reposition keeps it there)
    const cos = Math.cos(heading);
    const sin = Math.sin(heading);
    f.posX[i] = x + (ox * cos - oy * sin);
    f.posY[i] = y + (ox * sin + oy * cos);
    f.velX[i] = 0;
    f.velY[i] = 0;
    f.forceX[i] = 0;
    f.forceY[i] = 0;
    f.radius[i] = r;
    f.mass[i] = 1;
    f.energy[i] = RESERVE;
    f.cellType[i] = type;
    f.organismId[i] = org;
    f.genomeRef[i] = 0;
    f.brainRef[i] = 0;
    f.age[i] = 0;
    f.heading[i] = heading;
    f.senseX[i] = 0;
    f.senseY[i] = 0;
    f.thrust[i] = 0;
    return i;
  };

  // Body at the centre; passengers placed comfortably beyond the 2r contact range so the
  // kinematic group never soft-repels itself (asserted in critter.test). Offsets are
  // computed once and reused for both placement and the rigid-group table (no duplication).
  const off = 4 * r;
  const lat = off * 0.6;
  const aft = off * 1.8;
  const mover = make(CellType.MOVER, 0, 0);
  const sensorFwd = make(CellType.SENSOR, off, -lat);
  const sensorLat = make(CellType.SENSOR, off, lat);
  const clockA = make(CellType.NEURON, -off, -lat);
  const clockB = make(CellType.NEURON, -off, lat);
  const turn = make(CellType.NEURON, -aft, 0);
  const thrust = make(CellType.NEURON, aft, 0);

  const net = world.net;
  const g = (i: number): number => f.generation[i]!;

  // Sensor channels.
  net.addSensor(sensorFwd, SensorChannel.FWD_GRAD);
  net.addSensor(sensorLat, SensorChannel.LAT_GRAD);

  // Steering loop: lateral gradient → turn; forward gradient → thrust (+ cruise bias).
  net.addSynapse(sensorLat, g(sensorLat), turn, g(turn), 1.5);
  net.addSynapse(sensorFwd, g(sensorFwd), thrust, g(thrust), 1.5);
  net.bias[thrust] = 0.5; // forward cruise

  // Recurrent clock oscillator → a slow search sweep on the turn neuron.
  net.addSynapse(clockB, g(clockB), clockA, g(clockA), 0.9);
  net.addSynapse(clockA, g(clockA), clockB, g(clockB), -0.9);
  net.bias[clockA] = 0.2; // kick the oscillator off zero
  net.addSynapse(clockA, g(clockA), turn, g(turn), 0.3);

  // Motor binding: the MOVER reads (turn, thrust) neuron activations.
  net.addMotor(mover, turn, thrust);

  // Rigid group: every cell except the body is a passenger at its body-frame offset.
  world.addPassenger(sensorFwd, mover, off, -lat);
  world.addPassenger(sensorLat, mover, off, lat);
  world.addPassenger(clockA, mover, -off, -lat);
  world.addPassenger(clockB, mover, -off, lat);
  world.addPassenger(turn, mover, -aft, 0);
  world.addPassenger(thrust, mover, aft, 0);

  net.rebuildLive(world.cells);

  return { organismId: org, mover, sensorFwd, sensorLat, clockA, clockB, turn, thrust };
}
```

```ts
/**
 * §11 M4 deliverable — renders the neuron-cell network with LIVE activations.
 * Nodes are laid out from each neuron's world position (projected into the canvas);
 * node colour encodes activation (blue −1 → grey 0 → orange +1); synapse edges are
 * green (excitatory) / red (inhibitory), width ∝ |weight|. Read-only over core.
 */
export class BrainInspector {
  private readonly ctx: CanvasRenderingContext2D;
  constructor(private readonly canvas: HTMLCanvasElement) {
    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('brain inspector needs a 2D context');
    this.ctx = ctx;
  }

  render(world: World): void {
    const { ctx, canvas } = this;
    const w = canvas.width;
    const h = canvas.height;
    ctx.clearRect(0, 0, w, h);
    const net = world.net;
    const f = world.cells.fields;
    const n = net.liveNeuronCount;
    if (n === 0) {
      ctx.fillStyle = '#789';
      ctx.font = '12px monospace';
      ctx.fillText('no neuron cells', 10, 20);
      return;
    }

    // Bounding box of the live neurons in world space → fit to canvas with padding.
    let minX = Infinity;
    let minY = Infinity;
    let maxX = -Infinity;
    let maxY = -Infinity;
    for (let k = 0; k < n; k++) {
      const i = net.liveNeurons[k]!;
      const x = f.posX[i]!;
      const y = f.posY[i]!;
      if (x < minX) minX = x;
      if (x > maxX) maxX = x;
      if (y < minY) minY = y;
      if (y > maxY) maxY = y;
    }
    const pad = 24;
    const spanX = Math.max(1, maxX - minX);
    const spanY = Math.max(1, maxY - minY);
    const sx = (w - 2 * pad) / spanX;
    const sy = (h - 2 * pad) / spanY;
    const proj = (x: number, y: number): [number, number] => [
      pad + (x - minX) * sx,
      pad + (y - minY) * sy,
    ];

    // Edges (synapses).
    for (let k = 0; k < net.liveSynapseCount; k++) {
      const s = net.liveSynapses[k]!;
      const a = proj(f.posX[net.pre[s]!]!, f.posY[net.pre[s]!]!);
      const b = proj(f.posX[net.post[s]!]!, f.posY[net.post[s]!]!);
      const wgt = net.weight[s]!;
      ctx.strokeStyle = wgt >= 0 ? 'rgba(80,220,120,0.7)' : 'rgba(230,90,90,0.7)';
      ctx.lineWidth = Math.min(4, 0.5 + Math.abs(wgt));
      ctx.beginPath();
      ctx.moveTo(a[0], a[1]);
      ctx.lineTo(b[0], b[1]);
      ctx.stroke();
    }

    // Nodes (neurons), coloured by activation.
    for (let k = 0; k < n; k++) {
      const i = net.liveNeurons[k]!;
      const [px, py] = proj(f.posX[i]!, f.posY[i]!);
      const a = net.actCur[i]!; // ∈ roughly [−1, 1]
      const t = Math.max(-1, Math.min(1, a));
      // blue (−) → grey (0) → orange (+)
      const r = Math.round(120 + 110 * t);
      const g = Math.round(120 + 30 * Math.abs(t) * (t > 0 ? 1 : -1));
      const bl = Math.round(120 - 110 * t);
      ctx.fillStyle = `rgb(${r},${g},${bl})`;
      ctx.beginPath();
      ctx.arc(px, py, 7, 0, Math.PI * 2);
      ctx.fill();
      ctx.strokeStyle = '#cde';
      ctx.lineWidth = 1;
      ctx.stroke();
    }
  }
}
```
