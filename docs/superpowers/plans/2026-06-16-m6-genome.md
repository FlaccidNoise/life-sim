# M6 — Developmental Genome Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a developmental genome so organisms reproduce and can evolve toward complexity — a serializable genome (cell **genes** + a **development program** of division rules + a gene-keyed **connection-rule table** + **innovation IDs**), **deterministic isolated development** (a pure `genome → body` function grown in abstract parametric space with a fixed BFS rule-firing order, hard caps on cells-per-organism + recursion depth), **maternal provisioning** (§4.5; clean abort if under-provisioned), **asexual reproduction** (copy + mutate genome, provision + grow offspring), and **atomic organism death** (starved organism → cells become MEAT, death-driven bond reaping, id freed) — proven by a hand-authored genome that develops into the M5 critter and a reproduction loop whose offspring resemble the parent.

**Architecture:** A new pure `core/genome/` module owns the genome data model (`genome.ts`: `Gene`/`DivisionRule`/`BondRule`/`ConnectionRule`/`MotorRule`/`Genome` + a `GenomeStore` + clone/serialize), **deterministic development** (`develop.ts`: `develop(genome, caps) → DevelopedBody`, a pure RNG-free BFS over a rule queue producing a cell/bond/synapse plan in abstract local space), **mutation** (`mutate.ts`: Gaussian param perturbation, change-connection-weight, add/delete/duplicate gene-or-rule, rewire, change cell type, duplicate-subgraph — the only stochastic step, drawn from a dedicated RNG substream), and the **hand-authored critter genome** (`critter-genome.ts`). `core/organism/` gains **instantiation** (`instantiate.ts`: `instantiateBody` writes a `DevelopedBody` into the live `CellStore`/`NeuralNetwork`/`BondNetwork`/`OrganismTable`, transactional with a capacity pre-check → clean abort), **reproduction** (`reproduction.ts`: threshold scan + maternal provisioning + mutate→develop→instantiate + parent energy deduction), and **organism death** (`organism-death.ts`: atomic starved-organism death + bond reaping + id free). `World.tick` wires death then reproduction into the structural phase after `aggregateOrganisms`; `World` owns a `GenomeStore` + a `mutationRng = rng.split(2)`. The genome encodes cohesion (cell mass, bond stiffness, topology) per-organism, replacing the hand-tuned mass-2.

**Tech Stack:** TypeScript 6 strict, Vitest 4 (`--expose-gc` via `NODE_OPTIONS`), WebGL2, Vite 8, pnpm 11, Node 22. Determinism is an engineered invariant (development is RNG-free; mutation uses `rng.split(2)`); the per-tick hot loop is allocation-free (development/instantiation/reproduction/death are STRUCTURAL events that may allocate, like a critter build); energies/params written to cells are Float32 (`toBeCloseTo`, never `toBe`).

## Decisions locked with Josh (2026-06-16)

1. **Scope = reproduction-first.** Deliver genome + deterministic development; the hand-authored critter genome develops into the M5 critter (representational proof, unit + functional tests); asexual reproduction with maternal provisioning triggered by organism energy. Mutation operators are BUILT + unit-tested but **minimal / off-by-default** (per-operator rates default 0) — active selection/multi-generation drift is M7 (spec §10 Q-B seeds M7 from the hand-built critter).
2. **Brain-wiring = gene-keyed, bond-decoupled.** Each cell is an instance of a distinct **gene** (not just a palette type). `(preGene → postGene) ⇒ weight` wires a synapse between every instance-pair of those genes (1:1 for the critter). Distinct genes (`clockA` vs `clockB`, `turn` vs `thrust`, `sensorFwd` vs `sensorLat`) carry the critter's asymmetric weights + per-gene sensor-channel/bias. Decoupled from bond adjacency — matches M4's snapshotted-synapse design; can represent `sensorLat→turn` (which is NOT bonded).
3. **Reproduction = energy-threshold + maternal provisioning + atomic organism death.** Organism aggregate energy ≥ `reproThreshold` → parent provisions a seed with `body.totalEnergy` (enough to develop to a self-sustaining body) → offspring genome = copy+mutate → develop + instantiate near the parent. If the parent can't afford `body.totalEnergy` while keeping a floor → reproduction does not start (clean abort, never a half-grown corpse). **Organism death is ATOMIC** (whole organism dies when aggregate energy ≤ `organismDeathFloor` → all its cells → MEAT, all its bonds reaped, the id freed, nets rebuilt). Per-cell-death-within-an-organism + death-driven splits (the most emergent variant) are deferred (M7+).
4. **Development = isolated/deterministic + genome cohesion.** Grow the body in abstract parametric space via a fixed BFS rule-firing order (`develop` is a PURE function — RNG enters only at mutation), with hard caps on cells-per-organism + recursion depth, THEN instantiate into the world and let physics relax. The genome encodes cohesion (cell mass, bond stiffness, topology) per-organism, replacing the hand-tuned mass-2.

## Scope boundary (what M6 does NOT do — deferred, documented)

- **No active selection / multi-generation evolution tuning** (M7). Mutation operators exist + are unit-tested; per-operator rates default 0 (clone-only) so M6's demo offspring are exact copies ("maximal resemblance") and runs stay reproducible. Turning rates up + tuning the economy for emergent complexity is M7.
- **No per-cell death-within-an-organism + death-driven organism SPLIT.** M6 organism death is ATOMIC (the whole organism dies as a unit). The M5 STRAIN-break split mechanism (`SplitChecker`/`breakStrainedBonds`) is unchanged and still splits organisms whose bonds physically tear. A starving organism that loses one cell does not split — it dies whole when its aggregate energy hits the floor. (Per-cell mortality + death-split is M7+.)
- **No genome-gated adhesion-on-contact bond FORMATION.** Developed bodies are bonded AT INSTANTIATION (they do not need contact-formation to cohere), and the §8 acceptance does not require it, so the M5-deferred adhesion-formation stays deferred (it is best tuned alongside evolution in M7; the M5 adhesion FORCE remains present, default off). Cross-organism merging on contact is likewise deferred.
- **No per-organism brain PARTITIONING.** M6 keeps the single GLOBAL `NeuralNetwork`. Multiple organisms' brains coexist in one synapse pool correctly: every synapse connects two cells of ONE organism (development never wires across organisms), so THINK's global pass never mixes activations across bodies. Partitioning the net by organism graph is an M8 PERF optimisation (§5.3). On organism death M6 de-lists the severed synapses (`net.rebuildLive` — their endpoints become MEAT), **reclaims the dead cells' motor/sensor bindings** (`removeMotorsFor`/`removeSensorsFor` — `driveMovers` has no per-tick liveness guard, so a stale MOVER binding would ghost-thrust a corpse/recycled slot), and zeroes their activations + `thrust`.
- **Genome storage is plain JS objects** in a `GenomeStore` (`Map<ref, Genome>` + monotonic ref/innovation counters), NOT a SoA pool — genomes are touched only on structural events, never in the hot loop. Refs/innovation IDs are assigned deterministically (canonical reproduction order). A genome is freed when its organism dies (symmetry; bounded growth).
- **No toroidal-seam-correct development.** Bodies develop in a small local frame around the seed and are placed away from the seam; a developed organism that straddles the seam uses the existing per-bond `wrapDelta` rest-length computation (correct) but the plain-mean centroid (M5) is still seam-naive (M7/M8).

```ts
/**
 * The developmental genome (§4.7) — a growth recipe, not a blueprint. Plain JS data
 * (Float64 numbers); touched only on STRUCTURAL events (development, mutation,
 * reproduction), never in the allocation-free hot loop. Three parts (§4.7): cell GENES
 * (a parametric cell-type with a heritable innovation id), a DEVELOPMENT PROGRAM of
 * division rules, and gene-keyed BOND + CONNECTION + MOTOR rule tables that realise
 * non-tree bonds, synapses, and mover I/O over the developed body.
 *
 * Each cell of a developed body is an INSTANCE of a gene (decision 2). Rules are keyed by
 * GENE (not palette type), so distinct genes carry distinct wiring even when they share a
 * palette type (e.g. the critter's two clock NEURONs wire asymmetrically). With one
 * instance per gene this maps 1:1 to synapses; a recursive body's repeated instances are
 * all wired consistently by a single rule (§4.6 addressable-locus).
 */
export interface Gene {
  /** Heritable innovation/historical id (§4.7) for homology tracking (M9 crossover). */
  innovation: number;
  /** Palette type (CellType). */
  cellType: number;
  radius: number;
  mass: number;
  /** Seed energy provisioned per instance of this gene (sums into the maternal cost). */
  initialEnergy: number;
  /** Neuron bias (NEURON/MOVER); 0 otherwise. */
  bias: number;
  /** SensorChannel for a SENSOR gene; -1 otherwise. */
  sensorChannel: number;
}

/**
 * A division rule (§4.7): the `parentGene` emits `repeat` instances of `childGene`, each
 * placed at `dist` from the parent at body-frame angle `parentHeading + angle`, bonded to
 * the parent with relative `stiffness`. Fired in a fixed BFS order so development is
 * deterministic.
 */
export interface DivisionRule {
  parentGene: number;
  childGene: number;
  angle: number;
  dist: number;
  stiffness: number;
  repeat: number;
}

/** A non-tree bond between every instance-pair of two genes (bracing/cross-body cohesion). */
export interface BondRule {
  geneA: number;
  geneB: number;
  stiffness: number;
}

/** A synapse between every instance-pair (preGene → postGene) with weight/sign (§4.6). */
export interface ConnectionRule {
  preGene: number;
  postGene: number;
  weight: number;
}

/** Binds a MOVER gene's instance to read its (turn, thrust) neuron-gene instances. */
export interface MotorRule {
  moverGene: number;
  turnGene: number;
  thrustGene: number;
}

export interface Genome {
  /** Index into `genes` of the seed cell development starts from. */
  seedGene: number;
  genes: Gene[];
  divisionRules: DivisionRule[];
  bondRules: BondRule[];
  connectionRules: ConnectionRule[];
  motorRules: MotorRule[];
  /** Lineage: the parent genome's store ref (-1 for a founder). */
  parentRef: number;
  /** Lineage depth (0 for a founder). */
  generation: number;
}

/** Deep copy. Genes/rules are flat records, so a per-field copy is exact + allocation-cheap. */
export function cloneGenome(g: Genome): Genome {
  return {
    seedGene: g.seedGene,
    genes: g.genes.map((x) => ({ ...x })),
    divisionRules: g.divisionRules.map((x) => ({ ...x })),
    bondRules: g.bondRules.map((x) => ({ ...x })),
    connectionRules: g.connectionRules.map((x) => ({ ...x })),
    motorRules: g.motorRules.map((x) => ({ ...x })),
    parentRef: g.parentRef,
    generation: g.generation,
  };
}

export function serializeGenome(g: Genome): string {
  return JSON.stringify(g);
}

export function deserializeGenome(s: string): Genome {
  return JSON.parse(s) as Genome;
}

/**
 * Holds genomes by ref and hands out monotonic refs + innovation ids. Refs are NEVER
 * reused (a freed ref stays gone), so lineage references and `genomeRef` cell fields are
 * unambiguous and deterministic across runs given a canonical register order (reproduction
 * scans ascending organism id). Not in the hot loop — a Map is fine.
 */
export class GenomeStore {
  private readonly genomes: Map<number, Genome>;
  private nextRef: number;
  private innovation: number;

  constructor() {
    this.genomes = new Map<number, Genome>();
    this.nextRef = 0;
    this.innovation = 0;
  }

  /** Register a genome, returning its fresh ref. */
  register(g: Genome): number {
    const ref = this.nextRef++;
    this.genomes.set(ref, g);
    return ref;
  }

  get(ref: number): Genome | undefined {
    return this.genomes.get(ref);
  }

  /** Drop a genome (its organism died). The ref is not recycled. */
  free(ref: number): void {
    this.genomes.delete(ref);
  }

  /** Next heritable innovation id (monotonic; for new/duplicated genes). */
  nextInnovationId(): number {
    return this.innovation++;
  }

  get size(): number {
    return this.genomes.size;
  }
}
```

```ts
import { type Genome } from './genome';

/**
 * A developed body in abstract LOCAL space (seed at origin, heading 0) — the output of
 * deterministic isolated development (§4.7). Flat parallel arrays indexed by instance
 * 0..count-1 (instance order = BFS emit order = allocation order at instantiation). Bonds
 * carry local-instance endpoints + relative stiffness (rest length is computed from world
 * positions at instantiation, matching spawnSwimmer). `totalEnergy` is the maternal
 * provisioning requirement; `truncated` is set if a cap fired.
 */
export interface DevelopedBody {
  count: number;
  geneOf: number[];
  cellType: number[];
  radius: number[];
  mass: number[];
  initialEnergy: number[];
  bias: number[];
  sensorChannel: number[];
  localX: number[];
  localY: number[];
  localHeading: number[];
  bonds: { a: number; b: number; stiffness: number }[];
  synapses: { pre: number; post: number; weight: number }[];
  motors: { mover: number; turn: number; thrust: number }[];
  totalEnergy: number;
  truncated: boolean;
}

const TWO_PI = Math.PI * 2;

/**
 * Grow `genome` into a `DevelopedBody`. PURE — draws NO RNG (the seed→reproducible-body
 * guarantee), so two calls with the same genome are byte-identical. BFS over a rule queue
 * (children appended → processed level-order); turtle-graphics placement. Bounded by
 * `maxCells` (cells-per-organism cap) + `maxDepth` (recursion cap); either sets `truncated`.
 * Task 4 appends the gene-keyed bond/connection/motor tables.
 */
export function develop(genome: Genome, maxCells: number, maxDepth: number): DevelopedBody {
  const body: DevelopedBody = {
    count: 0, geneOf: [], cellType: [], radius: [], mass: [], initialEnergy: [],
    bias: [], sensorChannel: [], localX: [], localY: [], localHeading: [],
    bonds: [], synapses: [], motors: [], totalEnergy: 0, truncated: false,
  };
  const genes = genome.genes;
  const seed = genome.seedGene;
  if (seed < 0 || seed >= genes.length || maxCells <= 0) return body;

  const depthOf: number[] = [];
  const emit = (gene: number, x: number, y: number, heading: number, depth: number): number => {
    const gn = genes[gene]!;
    const i = body.count++;
    body.geneOf[i] = gene;
    body.cellType[i] = gn.cellType;
    body.radius[i] = gn.radius;
    body.mass[i] = gn.mass;
    body.initialEnergy[i] = gn.initialEnergy;
    body.bias[i] = gn.bias;
    body.sensorChannel[i] = gn.sensorChannel;
    body.localX[i] = x;
    body.localY[i] = y;
    body.localHeading[i] = heading;
    depthOf[i] = depth;
    body.totalEnergy += gn.initialEnergy;
    return i;
  };

  emit(seed, 0, 0, 0, 0);
  for (let head = 0; head < body.count; head++) {
    const parentGene = body.geneOf[head]!;
    const px = body.localX[head]!;
    const py = body.localY[head]!;
    const ph = body.localHeading[head]!;
    const pd = depthOf[head]!;
    for (let ri = 0; ri < genome.divisionRules.length; ri++) {
      const rule = genome.divisionRules[ri]!;
      if (rule.parentGene !== parentGene) continue;
      if (rule.childGene < 0 || rule.childGene >= genes.length) continue;
      const reps = rule.repeat > 0 ? rule.repeat : 1;
      const stepAngle = TWO_PI / reps;
      for (let k = 0; k < reps; k++) {
        if (pd + 1 > maxDepth) {
          body.truncated = true;
          break;
        }
        if (body.count >= maxCells) {
          body.truncated = true;
          return body;
        }
        const ch = ph + rule.angle + k * stepAngle;
        const cx = px + rule.dist * Math.cos(ch);
        const cy = py + rule.dist * Math.sin(ch);
        const child = emit(rule.childGene, cx, cy, ch, pd + 1);
        body.bonds.push({ a: head, b: child, stiffness: rule.stiffness });
      }
    }
  }
  return body;
}
```

```ts
import { type CellStore } from '../memory/cell-store';
import { type NeuralNetwork } from '../neural/network';
import { type BondNetwork } from './bonds';
import { type OrganismTable } from './organisms';
import { type DevelopedBody } from '../genome/develop';
import { CellType } from '../cells/types';
import { wrapDelta } from '../math/vec2';

/**
 * Instantiate a developed body into the live world (the second half of §4.7 development:
 * grow in abstract space, THEN instantiate + let physics relax). TRANSACTIONAL: a capacity
 * pre-check (cells / bonds / synapses / organism id / bond degree) means it allocates
 * NOTHING and returns −1 if anything is short — the clean-abort path so an under-provisioned
 * or over-capacity reproduction never leaves a half-built organism (§4.5). Local positions
 * are rotated by `heading` + translated to (x, y); each bond's rest length is computed from
 * the resulting WORLD positions via `wrapDelta`, exactly like spawnSwimmer, so a placed body
 * holds its geometry. Allocation-free: `slotScratch` (≥ maxCellsPerOrganism) is reused first
 * as a per-cell degree counter, then as the local→slot map. Returns the new organism id.
 */
export function instantiateBody(
  body: DevelopedBody,
  cells: CellStore,
  net: NeuralNetwork,
  bonds: BondNetwork,
  organisms: OrganismTable,
  genomeRef: number,
  x: number,
  y: number,
  heading: number,
  worldWidth: number,
  worldHeight: number,
  slotScratch: Int32Array,
): number {
  const count = body.count;
  if (count <= 0 || count > slotScratch.length) return -1;
  if (cells.capacity - cells.aliveCount < count) return -1;
  if (bonds.freeCount < body.bonds.length) return -1;
  if (net.synFreeCount < body.synapses.length) return -1;
  // Sensor/motor binding pools (sized maxNeurons = the binding arrays' length). Guarding these
  // keeps the "never half-builds" promise for bodies with sensors/motors, and pairs with the
  // death-time reclaim (removeMotorsFor/removeSensorsFor) so the counts stay bounded.
  let bodySensors = 0;
  for (let i = 0; i < count; i++) {
    if (body.sensorChannel[i]! >= 0 && body.cellType[i]! === CellType.SENSOR) bodySensors++;
  }
  if (net.sensorCount + bodySensors > net.sensorCell.length) return -1;
  if (net.motorCount + body.motors.length > net.moverCell.length) return -1;

  // Degree pre-check: reuse slotScratch as a per-cell bond-degree counter.
  for (let i = 0; i < count; i++) slotScratch[i] = 0;
  for (let bi = 0; bi < body.bonds.length; bi++) {
    const bd = body.bonds[bi]!;
    slotScratch[bd.a] = slotScratch[bd.a]! + 1;
    slotScratch[bd.b] = slotScratch[bd.b]! + 1;
  }
  const degCap = bonds.degreeCap;
  for (let i = 0; i < count; i++) if (slotScratch[i]! > degCap) return -1;

  const org = organisms.alloc();
  if (org < 0) return -1;

  const f = cells.fields;
  const cos = Math.cos(heading);
  const sin = Math.sin(heading);

  // Alloc + place cells in BFS order; slotScratch[local] = slot (overwrites the degree counts).
  for (let i = 0; i < count; i++) {
    const slot = cells.alloc();
    slotScratch[i] = slot;
    const lx = body.localX[i]!;
    const ly = body.localY[i]!;
    f.posX[slot] = x + (lx * cos - ly * sin);
    f.posY[slot] = y + (lx * sin + ly * cos);
    f.velX[slot] = 0;
    f.velY[slot] = 0;
    f.forceX[slot] = 0;
    f.forceY[slot] = 0;
    f.radius[slot] = body.radius[i]!;
    f.mass[slot] = body.mass[i]!;
    f.energy[slot] = body.initialEnergy[i]!;
    f.cellType[slot] = body.cellType[i]!;
    f.organismId[slot] = org;
    f.genomeRef[slot] = genomeRef;
    f.brainRef[slot] = 0;
    f.age[slot] = 0;
    f.heading[slot] = heading;
    f.senseX[slot] = 0;
    f.senseY[slot] = 0;
    f.thrust[slot] = 0;
    net.actCur[slot] = 0; // zero neural state for a recycled slot
    net.actNxt[slot] = 0;
    net.bias[slot] = body.bias[i]!;
  }

  // Bonds: rest length from world positions (wrapDelta), like spawnSwimmer.
  for (let bi = 0; bi < body.bonds.length; bi++) {
    const bd = body.bonds[bi]!;
    const a = slotScratch[bd.a]!;
    const b = slotScratch[bd.b]!;
    const dx = wrapDelta(f.posX[a]! - f.posX[b]!, worldWidth);
    const dy = wrapDelta(f.posY[a]! - f.posY[b]!, worldHeight);
    bonds.addBond(a, f.generation[a]!, b, f.generation[b]!, Math.sqrt(dx * dx + dy * dy), bd.stiffness);
  }

  // Synapses.
  for (let si = 0; si < body.synapses.length; si++) {
    const sy = body.synapses[si]!;
    const pre = slotScratch[sy.pre]!;
    const post = slotScratch[sy.post]!;
    net.addSynapse(pre, f.generation[pre]!, post, f.generation[post]!, sy.weight);
  }

  // Sensor channels (SENSOR genes carry a channel).
  for (let i = 0; i < count; i++) {
    const ch = body.sensorChannel[i]!;
    if (ch >= 0 && body.cellType[i]! === CellType.SENSOR) net.addSensor(slotScratch[i]!, ch);
  }

  // Motors.
  for (let mi = 0; mi < body.motors.length; mi++) {
    const mo = body.motors[mi]!;
    net.addMotor(slotScratch[mo.mover]!, slotScratch[mo.turn]!, slotScratch[mo.thrust]!);
  }

  organisms.mover[org] = body.motors.length > 0 ? slotScratch[body.motors[0]!.mover]! : -1;
  organisms.genomeRef[org] = genomeRef;

  net.rebuildLive(cells);
  bonds.rebuildLive(cells);
  return org;
}
```

```ts
import { type Genome, cloneGenome } from './genome';
import { type Rng } from '../math/rng';

/** Per-operator mutation rates + Gaussian σ (all live Config knobs; default 0 in M6). */
export interface MutationRates {
  paramSigma: number;
  paramRate: number;
  weightSigma: number;
  weightRate: number;
  addGeneRate: number;
  deleteGeneRate: number;
  duplicateGeneRate: number;
  rewireRate: number;
  changeTypeRate: number;
  duplicateSubgraphRate: number;
}

/** Standard-normal sample via Box–Muller. Deterministic from `rng` (two floats per call). */
export function gaussian(rng: Rng): number {
  let u1 = rng.float();
  if (u1 < 1e-12) u1 = 1e-12;
  const u2 = rng.float();
  return Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
}

/**
 * Produce a mutated copy of `parent` (§4.7). Operators are applied in a FIXED order, each
 * gated by its rate, drawing from `rng` (reproduction passes a `rng.split(2)` substream) —
 * so a given (parent, rng state, rates) is byte-deterministic. With all rates 0 the result
 * is an exact clone (M6 reproduction-first). Lineage (`parentRef`/`generation`) is set by
 * the caller, not here. Tasks 10–11 add the structural operators (which take a `GenomeStore`
 * for fresh innovation ids).
 */
export function mutateGenome(parent: Genome, rng: Rng, rates: MutationRates): Genome {
  const child = cloneGenome(parent);

  // Numeric gene-param perturbation.
  for (let gi = 0; gi < child.genes.length; gi++) {
    if (rng.float() < rates.paramRate) {
      const gene = child.genes[gi]!;
      gene.radius = Math.max(0.5, gene.radius + gaussian(rng) * rates.paramSigma);
      gene.mass = Math.max(0.1, gene.mass + gaussian(rng) * rates.paramSigma);
      gene.initialEnergy = Math.max(0, gene.initialEnergy + gaussian(rng) * rates.paramSigma);
      gene.bias = gene.bias + gaussian(rng) * rates.paramSigma;
    }
  }

  // Connection-weight perturbation (the addressable synapse-weight locus, §4.6).
  for (let ci = 0; ci < child.connectionRules.length; ci++) {
    if (rng.float() < rates.weightRate) {
      child.connectionRules[ci]!.weight += gaussian(rng) * rates.weightSigma;
    }
  }

  return child;
}
```

```ts
  if (rng.float() < rates.deleteGeneRate && child.genes.length > 1) {
    // Pick a victim among non-seed genes.
    let victim = rng.int(child.genes.length);
    if (victim === child.seedGene) victim = (victim + 1) % child.genes.length;
    if (victim !== child.seedGene) {
      const remap: number[] = [];
      let next = 0;
      for (let i = 0; i < child.genes.length; i++) remap[i] = i === victim ? -1 : next++;
      child.genes = child.genes.filter((_, i) => i !== victim);
      child.seedGene = remap[child.seedGene]!;
      child.divisionRules = child.divisionRules
        .filter((r) => r.parentGene !== victim && r.childGene !== victim)
        .map((r) => ({ ...r, parentGene: remap[r.parentGene]!, childGene: remap[r.childGene]! }));
      child.bondRules = child.bondRules
        .filter((r) => r.geneA !== victim && r.geneB !== victim)
        .map((r) => ({ ...r, geneA: remap[r.geneA]!, geneB: remap[r.geneB]! }));
      child.connectionRules = child.connectionRules
        .filter((r) => r.preGene !== victim && r.postGene !== victim)
        .map((r) => ({ ...r, preGene: remap[r.preGene]!, postGene: remap[r.postGene]! }));
      child.motorRules = child.motorRules
        .filter((r) => r.moverGene !== victim && r.turnGene !== victim && r.thrustGene !== victim)
        .map((r) => ({ ...r, moverGene: remap[r.moverGene]!, turnGene: remap[r.turnGene]!, thrustGene: remap[r.thrustGene]! }));
    }
  }

  // Duplicate a subgraph: copy a root gene + the genes reachable via division rules from it,
  // with fresh innovation ids + remapped division rules, and attach the copied root to the
  // seed. The key complexity driver (§4.7).
  if (rng.float() < rates.duplicateSubgraphRate && child.genes.length > 0) {
    const root = rng.int(child.genes.length);
    // BFS the subtree of genes reachable from `root` via division rules.
    const inSub: number[] = [root];
    const seen = new Set<number>([root]);
    for (let h = 0; h < inSub.length; h++) {
      const gp = inSub[h]!;
      for (let ri = 0; ri < child.divisionRules.length; ri++) {
        const r = child.divisionRules[ri]!;
        if (r.parentGene === gp && !seen.has(r.childGene)) {
          seen.add(r.childGene);
          inSub.push(r.childGene);
        }
      }
    }
    // Copy each subtree gene with a fresh innovation id; map old → new index.
    const copyIndex = new Map<number, number>();
    for (let k = 0; k < inSub.length; k++) {
      const old = inSub[k]!;
      const copy: Gene = { ...child.genes[old]!, innovation: store.nextInnovationId() };
      copyIndex.set(old, child.genes.push(copy) - 1);
    }
    // Replicate the internal division rules among the copies.
    const internal = child.divisionRules.filter((r) => copyIndex.has(r.parentGene) && copyIndex.has(r.childGene));
    for (let ri = 0; ri < internal.length; ri++) {
      const r = internal[ri]!;
      child.divisionRules.push({ ...r, parentGene: copyIndex.get(r.parentGene)!, childGene: copyIndex.get(r.childGene)! });
    }
    // Attach the copied root to the seed so the duplicated limb actually develops.
    child.divisionRules.push({
      parentGene: child.seedGene,
      childGene: copyIndex.get(root)!,
      angle: rng.range(0, Math.PI * 2),
      dist: rng.range(12, 30),
      stiffness: 1,
      repeat: 1,
    });
  }

  return child;
```

```ts
import { type CellStore } from '../memory/cell-store';
import { type NeuralNetwork } from '../neural/network';
import { type BondNetwork } from './bonds';
import { type OrganismTable } from './organisms';
import { type GenomeStore } from '../genome/genome';
import { type Rng } from '../math/rng';
import { type MutationRates, mutateGenome } from '../genome/mutate';
import { develop } from '../genome/develop';
import { instantiateBody } from './instantiate';
import { wrap } from '../math/vec2';

/** Scalar parameters for one reproduction pass (plain data — NOT Config). */
export interface ReproParams {
  reproThreshold: number;
  parentFloor: number;
  offspringOffset: number;
  maxCellsPerOrganism: number;
  maxRecursionDepth: number;
  maxBirthsPerTick: number;
  worldWidth: number;
  worldHeight: number;
  tick: number;
}

/**
 * Asexual reproduction (§4.5). Scans organisms in ascending id (canonical → deterministic
 * mutation draws). An organism with aggregate energy ≥ `reproThreshold` and a genome
 * copy+mutates (draws from `mutationRng`, the rng.split(2) substream) + develops an
 * offspring; if it can afford `body.totalEnergy` while retaining `parentFloor`, it
 * instantiates the offspring near its centroid and deducts the provision from its cells
 * (MATERNAL PROVISIONING). Under-provisioned / over-capacity / degenerate(truncated)
 * development → clean abort (no allocation). Bounded by `maxBirthsPerTick`. STRUCTURAL — runs
 * once per tick in the §4.3 step-8 phase; allocates on an actual birth, not on the scan.
 */
export function reproduceOrganisms(
  cells: CellStore,
  net: NeuralNetwork,
  bonds: BondNetwork,
  organisms: OrganismTable,
  store: GenomeStore,
  liveIndices: Uint32Array,
  liveCount: number,
  mutationRng: Rng,
  rates: MutationRates,
  params: ReproParams,
  slotScratch: Int32Array,
  out: { births: number },
): void {
  const f = cells.fields;
  let births = 0;
  const maxOrg = organisms.maxOrganisms;

  for (let org = 1; org < maxOrg; org++) {
    if (births >= params.maxBirthsPerTick) break;
    if (!organisms.isAlive(org)) continue;
    if (organisms.cellCount[org]! === 0) continue;
    if (organisms.energy[org]! < params.reproThreshold) continue;
    const parentRef = organisms.genomeRef[org]!;
    if (parentRef < 0) continue;
    const parentGenome = store.get(parentRef);
    if (parentGenome === undefined) continue;

    const childGenome = mutateGenome(parentGenome, mutationRng, rates, store);
    childGenome.parentRef = parentRef;
    childGenome.generation = parentGenome.generation + 1;

    const body = develop(childGenome, params.maxCellsPerOrganism, params.maxRecursionDepth);
    if (body.count === 0 || body.truncated) continue; // degenerate → clean skip

    const orgEnergy = organisms.energy[org]!;
    if (orgEnergy - body.totalEnergy < params.parentFloor) continue; // under-provisioned → clean abort

    const cx = wrap(organisms.centroidX[org]! + params.offspringOffset, params.worldWidth);
    const cy = organisms.centroidY[org]!;
    const mover = organisms.mover[org]!;
    const heading = mover >= 0 ? f.heading[mover]! : 0;

    const childRef = store.register(childGenome);
    const newOrg = instantiateBody(
      body, cells, net, bonds, organisms, childRef, cx, cy, heading, params.worldWidth, params.worldHeight, slotScratch,
    );
    if (newOrg < 0) {
      store.free(childRef); // capacity → clean abort, undo the registration
      continue;
    }
    organisms.birthTick[newOrg] = params.tick;

    // Maternal provisioning: deduct body.totalEnergy from the parent's cells proportionally.
    const scale = orgEnergy > 0 ? (orgEnergy - body.totalEnergy) / orgEnergy : 0;
    for (let k = 0; k < liveCount; k++) {
      const i = liveIndices[k]!;
      if (f.organismId[i]! === org) f.energy[i] = f.energy[i]! * scale;
    }
    births++;
  }

  out.births = births;
}
```

```ts
import { type CellStore } from '../memory/cell-store';
import { type NeuralNetwork } from '../neural/network';
import { type BondNetwork } from './bonds';
import { type OrganismTable } from './organisms';
import { type GenomeStore } from '../genome/genome';
import { CellType } from '../cells/types';

/**
 * Atomic organism death (§4.8, the M5-deferred death cascade). An organism whose aggregate
 * energy ≤ `deathFloor` dies as a WHOLE: each of its cells becomes free MEAT (`organismId`
 * → 0, energy = mass·`meatEnergyOnDeath`, velocity zeroed), all its bonds are reaped
 * (death-driven bond reaping), its neural activations are zeroed (the caller's
 * `net.rebuildLive` then de-lists the now-non-neural synapses, and motor/sensor bindings are
 * reclaimed via removeMotorsFor/removeSensorsFor), and its organism id + genome
 * are freed. The MEAT cells decay + free normally via the cell-level lifecycle next tick.
 * Returns true if any organism died (→ caller rebuilds the nets). Allocation-free: `dying`
 * is a pre-allocated per-organism flag buffer (length ≥ maxOrganisms).
 */
export function killStarvedOrganisms(
  cells: CellStore,
  net: NeuralNetwork,
  bonds: BondNetwork,
  organisms: OrganismTable,
  store: GenomeStore,
  liveIndices: Uint32Array,
  liveCount: number,
  deathFloor: number,
  meatEnergyOnDeath: number,
  dying: Uint8Array,
  out: { deaths: number },
): boolean {
  const maxOrg = organisms.maxOrganisms;
  let deaths = 0;
  for (let org = 1; org < maxOrg; org++) {
    // genomeRef guard: genome-less organisms (M5 hand-built clusters, strain-split fragments)
    // are M5-immortal (lifecycle-exempt) — only genome-bearing M6 organisms die atomically.
    if (
      organisms.isAlive(org) &&
      organisms.genomeRef[org]! >= 0 &&
      organisms.cellCount[org]! > 0 &&
      organisms.energy[org]! <= deathFloor
    ) {
      dying[org] = 1;
      deaths++;
    } else {
      dying[org] = 0;
    }
  }
  if (deaths === 0) {
    out.deaths = 0;
    return false;
  }

  const f = cells.fields;
  const cap = bonds.degreeCap;
  for (let k = 0; k < liveCount; k++) {
    const i = liveIndices[k]!;
    const org = f.organismId[i]!;
    if (org === 0 || dying[org] === 0) continue;
    // Reap every bond on this cell (swap-remove keeps adj[off+0] valid each iteration).
    while (bonds.degree[i]! > 0) bonds.removeBond(bonds.adj[i * cap]!);
    // Convert to free MEAT carrying biomass energy.
    f.cellType[i] = CellType.MEAT;
    f.energy[i] = f.mass[i]! * meatEnergyOnDeath;
    f.organismId[i] = 0;
    f.velX[i] = 0;
    f.velY[i] = 0;
    f.thrust[i] = 0; // kill stale motor drive BEFORE the binding is gone (no corpse self-propulsion)
    // Reclaim this cell's motor/sensor bindings (driveMovers has no per-tick liveness guard, so a
    // lingering MOVER binding would drive ghost thrust onto this MEAT slot — and onto whatever the
    // slot recycles into) + zero severed activations (the slot may recycle into a new neuron).
    net.removeMotorsFor(i);
    net.removeSensorsFor(i);
    net.actCur[i] = 0;
    net.actNxt[i] = 0;
  }

  // Free the dead organisms' ids + genomes.
  for (let org = 1; org < maxOrg; org++) {
    if (dying[org] === 1) {
      const ref = organisms.genomeRef[org]!;
      if (ref >= 0) store.free(ref);
      organisms.free(org);
    }
  }

  out.deaths = deaths;
  return true;
}
```

```ts
/** Render an organism's genome + lineage into a text panel (§11 M6 genome/lineage inspector). */
export function renderGenomeInspector(world: World, org: number, panel: HTMLElement): void {
  if (org <= 0 || !world.organisms.isAlive(org)) {
```

```ts
// M6 demo: a critter DEVELOPED from its genome (proves the encoding drives the live demo),
// plus a cluster of autotrophs that photosynthesise, accumulate energy, and REPRODUCE —
// offspring resemble the parent (clone-only at the default mutation rates).
function developInto(genome: ReturnType<typeof buildCritterGenome>, x: number, y: number, heading: number): number {
  const ref = world.genomes.register(genome);
  const body = develop(genome, world.config.maxCellsPerOrganism, world.config.maxRecursionDepth);
  return instantiateBody(body, world.cells, world.net, world.bonds, world.organisms, ref, x, y, heading, world.config.worldWidth, world.config.worldHeight, world.instantiateScratch);
}
developInto(buildCritterGenome(world.config.cellRadius), world.config.worldWidth * 0.5 - 120, world.config.worldHeight * 0.5, 0);
for (let k = 0; k < 12; k++) {
  developInto(buildAutotrophGenome(world.config.cellRadius), world.config.worldWidth * 0.5 + 200 + (k % 4) * 60, world.config.worldHeight * 0.5 + ((k / 4) | 0) * 60, 0);
}
```
